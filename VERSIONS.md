# Version history

Each version is a successive commit of **the same `SWaP.user.js` file**. Tags let you inspect that version without keeping many installable duplicates on the main branch. Import commits were created together in version order; their dates are not original release dates.

**Install only the current SWaP release.** Older Sidekick versions are preserved for reference and do not contain the new room-authentication protections. Their original branding and userscript metadata remain unchanged.
