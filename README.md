# SWaP historical archive

This commit preserves the original Sidekick 3.1.0 userscript, unchanged, under the common `SWaP.user.js` filename. Imported in version order; commit dates reflect the import, not the original release dates.

**Historical and unsupported. Use the latest release on the main branch for normal installation.** Older versions do not include SWaP 4.0 room authentication and security hardening. Original metadata/branding is intentionally preserved in this snapshot.

The original installation method was Tampermonkey → Create a new script → replace the template with the entire userscript → save → reload https://web.stremio.com/. Keep only one script enabled.

Standalone Chrome extension: planned, not available.
